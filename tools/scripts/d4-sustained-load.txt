# D4: sustained receive with the engine running. Targets throughput and
# back-pressure, RxStatus and per-protocol status masks, and whether anything is
# dropped between the bus and the API.
#
# readstats rather than readfor: at these rates per-message logging is useless
# and enormous (a five minute run produced 736512 messages and a 69 MB log). It
# prints eight sample messages, then aggregates - totals, rate against the device
# microsecond clock, unique CAN IDs, the largest timestamp gap, and a histogram
# of every RxStatus value seen.
open dev
connect dev CAN NONE 500000 chan
filter chan PASS CAN NONE 00000000 00000000 f
readstats chan 256 1000 300
stopfilter chan f
disconnect chan
close dev
