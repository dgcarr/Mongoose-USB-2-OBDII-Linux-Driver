# H8: GET_CONFIG on a raw CAN channel, read only.
# One parameter per call, so each ID's result is visible: the vendor (and this driver) fail a whole list at
# the first ID the channel does not have. A refused ID prints a nonzero result and the script goes on.
open dev
connect dev CAN NONE 500000 chan
mark DATA_RATE
getconfig chan 0x1
mark LOOPBACK
getconfig chan 0x3
mark BIT_SAMPLE_POINT
getconfig chan 0x17
mark SYNC_JUMP_WIDTH
getconfig chan 0x18
mark DT_PULLUP_VALUE
getconfig chan 0x10008
mark (unassigned)
getconfig chan 0x2
mark ISO15765_BS: ISO15765 only, so unsupported here
getconfig chan 0x1e
mark J1962_PINS: only on *_PS protocols
getconfig chan 0x8001
disconnect chan
close dev
